Bioinformatics pipeline organization strucure:

data: where the raw reads are stored.

src: where the scripts are writen and stored.
     available scripts are;
	pipeline.py
	pipeline.R

results: where the output are diplayed and stored.

Software requirements
fastqc v.0.12.1

Installation procedure on Linux operating system
Open your OS; Ubuntu MobaXterm
use the command:

mamba install fastqc v.0.12.1.
